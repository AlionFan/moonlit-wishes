# 月下寄心意

由岩火AI教育温暖支持的中秋音乐祝福卡。已部署在 Joybeat，正式地址：**https://mid-autumn.joybeat.cn/**。手机优先，三个独立入口：

- 致朋友：`/?to=friend`
- 致前辈：`/?to=elder`
- 致师长：`/?to=teacher`

每张卡都是独立的七屏手机 H5：月下相逢、心中有你、一纸祝福、三句祝愿、片刻静好、一曲清音、再寄心意。三个收卡入口彼此不展示切换选项；制作新卡时可以在朋友、长辈、师长之间选择。支持上下或左右滑动、按钮翻页、定制收件人和署名、编辑祝福、切歌、音量、15/30/60 分钟定时、复制链接、二维码海报保存。品牌只在页脚轻署名。

手机端的封面寄语为 20px，祝福信、故事和静心引导为 19px，并使用较粗字重；顶部制作入口有箭头指引，页内继续按钮和底部“下一页”均放大加粗。长页显示上滑提示，继续滑动可读完署名和后续按钮。

## 私人统计

在 [心意卡统计](https://mid-autumn.joybeat.cn/stats.html) 输入部署时生成的访问口令，可查看制作人数、制作并操作分享的人数、分享操作次数，以及卡片被其他浏览器打开的数量。按三类祝福及分享方式分别汇总。统计从启用本功能之时开始，不追溯此前的卡片；只保存匿名浏览器标识、不可读的卡片摘要和操作类型，不保存姓名或祝福文字。复制链接和下载海报代表用户执行了分享准备操作，不能证明消息已发送；“被他人打开”是更接近实际传播的指标。

## 运行

需要 Node.js 22.18+。

```sh
npm install
npm run dev
```

开发预览默认 http://localhost:5173/ 。发布构建：

```sh
npm test
npm run build
npm run preview -- --port 4173
```

构建产物位于 `dist/`。三款入口使用查询参数，无需配置页面重写。线上采用独立 Nginx 服务，由 Joybeat 现有代理提供 HTTPS。发布与回滚说明见 `docs/joybeat-deployment.md`。

## 分享方式

姓名、署名、祝福和曲目编号编码在链接片段中，不依赖数据库或登录。收件人打开该链接即可还原卡片；最后一页能制作新的卡片。二维码指向相同链接。

正式分享需要公开可访问的 HTTPS 域名。生成链接会自动采用打开网站时的域名。本机预览时会显示提示。分享弹窗会指引微信用户点击右上角「···」转发给好友；制作海报后可长按图片分享。复制链接是单独的备用操作。微信链接预览效果可能因客户端版本而异；自定义微信分享信息需已认证公众号及 JS-SDK，本项目不包含这些账号设置。

打开页面会立即尝试播放音乐。微信内置浏览器及 iOS 等环境可能拦截有声自动播放；此时首次轻触卡片便开始播放，并显示提示。离开网页或系统进入省电状态后，定时精度由浏览器调度决定。

## 检查

- 六项分享数据测试：中文和 emoji、三类入口、损坏链接、非法字段、最长祝福、跨对象链接隔离。
- 两项统计测试：去重与他人打开的口径、只接受匿名标识的事件格式。
- 浏览器实测：手机与桌面布局、播放/暂停、切歌、定时选项、定制生成、复制链接、新窗口还原、1080×1600 海报生成。
- 线上实测：三个入口、16 项页面与资源请求、音频分段读取、HTTPS 证书、HTTP 自动跳转、播放/暂停、定制卡片、新窗口还原、复制粘贴链接、海报生成及手机页面。
- 尚未在真实微信客户端验证分享展示；未接入微信 JS-SDK。
